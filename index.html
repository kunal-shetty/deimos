Deimos is a terminal-native coding agent that does not simply respond — it reasons. Given a task, it forms a dependency-aware plan before writing a single line, asks clarifying questions to resolve ambiguity, and executes step by step with precise tool use.

Between sessions, it retains what it learned: your codebase structure, your patterns, the decisions already made. Named for the moon of Mars — the embodiment of dread and precision — it moves in silence and acts without hesitation.

DEPLOYMENT
Get started in 60 seconds

One command to assemble the agent.

deimos — zsh
# Quick install — Unix / Bash / WSL
$curl -sSL https://deimos.sh/install | sh
# Launch the agent
$deimos assemble
# Or monitor it live
$deimos dashboard
# Manual install — Windows / PowerShell
>git clone https://github.com/kunal-shetty/deimos
>cd deimos
>python -m venv .venv
>.\.venv\Scripts\activate
>pip install .
# Create .env in the project root
GROQ_API_KEY=your_groq_api_key
TAVILY_API_KEY=your_tavily_api_key
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-anon-key
DEIMOS_USER_ID=your-user-uuid
# Initialize Supabase schema — see docs/installation.md
