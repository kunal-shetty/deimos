DEIMOS

An open-source coding agent for your terminal. Press play, pause anywhere, and select text in the recording.

Press play to start the 80 second walkthrough.

This is a recording of the real installed program, not a sandbox you can type in. Tools, permission prompts, checkpoints and pytest all ran for real. Model replies and model decisions were scripted so that the recording is repeatable, which is why the welcome box says model: scripted-demo. Install wait is sped up and idle pauses are shortened.

Try it yourself

curl -fsSL https://raw.githubusercontent.com/kunal-shetty/deimos/main/scripts/install.sh | sh
irm https://raw.githubusercontent.com/kunal-shetty/deimos/main/scripts/install.ps1 | iex
